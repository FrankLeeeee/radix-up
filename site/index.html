Install

radix-up is a single bash script. npm is only used to put it on your PATH and to remove it again.

Install or upgrade

npm install -g github:FrankLeeeee/radix-up

Uninstall

npm uninstall -g radix-up

Requires macOS or Linux with bash, ssh, tar, jq, and the radix CLI logged in with radix login. Your projects live in ~/.config/radix-up and survive uninstalls.

Usage

Create a project once, then use radix-up assign wherever you used radix assign. Every radix assign flag is passed through.

radix login                                   # once
radix-up init                                 # create the default project
radix-up init specforge                       # create a named project
radix-up assign <machine-id> --project specforge

What happens on assign

Assign

Checks the project exists, then runs radix --json assign, which returns instead of opening a shell.

Connect

Reads the user, IP and proxy for each machine and waits until SSH accepts your key.

Init

Runs the project's init.sh for every machine in parallel, with connection details in env vars.

Work

Jump in with radix-up ssh <machine-id>. Logs are kept per run.

Commands

CommandWhat it does
radix-up init [project]Create a project from the template (default if no name).
radix-up listList projects and their paths.
radix-up assign <args> [--project NAME]Assign machines, then run the project's init script on each.
radix-up setup <machine-id> [--project NAME]Re-run an init script on a machine you already hold.
radix-up ssh <machine-id> [cmd]SSH in with the same user, key and proxy.
radix-up logs [machine-id] [-f]Show or follow the latest init log.
radix-up infoShow saved connection info for your active machines.

Editing init scripts

Each project is a folder with an init.sh and a files/ directory. Edit them with any editor; radix-up list shows where they are.

~/.config/radix-up/
├── projects/
│   ├── default/            # used when --project is omitted
│   │   ├── init.sh
│   │   └── files/          # copied to ~ on the node by `push files`
│   └── specforge/
│       ├── init.sh
│       └── files/
├── state/                  # saved connection info per machine
└── logs/                   # one log per init run

The shape of an init script

init.sh runs on your machine. Use push to copy files over and remote to run commands on the node.

set -euo pipefail
source "$RADIX_UP_LIB"          # gives you `push` and `remote`

push files                      # ./files/* -> ~ on the node

remote <<'EOF'                  # everything below runs on the node
set -euo pipefail
echo "hello from $RADIX_MACHINE_ID (rank $RADIX_NODE_RANK)"
EOF

Helpers

remote nvidia-smi                # run one command on the node
remote <<'EOF'                   # run a bash script on the node
cd ~/SpecForge && git pull
EOF

push files                       # copy ./files/* into ~
push ~/.gitconfig                # copy a single file into ~
push ~/.ssh/my_key .ssh          # copy into ~/.ssh

Variables

VariableMeaning
RADIX_MACHINE_IDMachine ID
RADIX_SSH_USER, RADIX_NODE_IP, RADIX_SSH_PORTWhere to connect, from radix assign
RADIX_SSH_KEYThe key radix uploads ($RADIX_SSH_KEY or ~/.ssh/id_ed25519)
RADIX_PROXY_JUMPBastion host, if any
RADIX_NODE_RANK, RADIX_NUM_NODES, RADIX_NODE_IPSFor multi-machine assigns
RADIX_PROJECT, RADIX_PROJECT_DIRProject name and folder (also the working directory)

Inside remote scripts, RADIX_MACHINE_ID, RADIX_NODE_RANK, RADIX_NUM_NODES, RADIX_NODE_IPS and RADIX_PROJECT are set too.

Secrets

Put tokens in files/.radix_env. The template copies it to the node, locks it to your user, and loads it from ~/.bashrc; it also makes ~/.profile load ~/.bashrc, because radix shell starts a login shell.

# ~/.config/radix-up/projects/<name>/files/.radix_env
HF_TOKEN=hf_...
WANDB_API_KEY=...
CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-...
Nodes are rootless. There is no sudo or apt-get; install tools into $HOME (uv, rustup, the Codex and Claude installers). Keep scripts idempotent, e.g. [[ -d repo ]] || git clone …, so radix-up setup can re-run them.

Examples

Drop any of these into a project's init.sh, or combine them. Each one can be re-run safely.

Copy a private key to the node so git clone git@github.com:… and git push work. It is locked to your user and used only for github.com.

set -euo pipefail
source "$RADIX_UP_LIB"

# Private key that GitHub knows (or any other git host)
push ~/.ssh/github_key .ssh

remote <<'EOF'
set -euo pipefail
chmod 700 ~/.ssh && chmod 600 ~/.ssh/github_key

# Trust GitHub's host key so the first clone doesn't prompt
grep -q github.com ~/.ssh/known_hosts 2>/dev/null \
  || ssh-keyscan -t ed25519 github.com >> ~/.ssh/known_hosts 2>/dev/null

# Use this key for github.com
if ! grep -q '^Host github.com' ~/.ssh/config 2>/dev/null; then
  printf 'Host github.com\n  IdentityFile ~/.ssh/github_key\n  IdentitiesOnly yes\n' >> ~/.ssh/config
  chmod 600 ~/.ssh/config
fi

# Prints "Hi <you>! You've successfully authenticated ..."
ssh -T git@github.com 2>&1 | head -1 || true
EOF

Install uv and Rust, then clone SGLang and install it from source into a uv virtual env. Put HF_TOKEN in files/.radix_env for gated models.

set -euo pipefail
source "$RADIX_UP_LIB"

push files                                   # .radix_env with HF_TOKEN=...

remote <<'EOF'
set -euo pipefail
set -a; source ~/.radix_env; set +a

# uv (rootless, installs to ~/.local/bin)
command -v uv >/dev/null || curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"

# Rust (rootless, installs to ~/.cargo; -y skips the interactive prompt)
command -v cargo >/dev/null || curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# SGLang from source, in its own virtual env
cd ~
[[ -d sglang ]] || git clone https://github.com/sgl-project/sglang.git
cd sglang
[[ -d .venv ]] || uv venv -p 3.11 --seed
source .venv/bin/activate
uv pip install -e "python[all]" --prerelease=allow

python -c "import sglang; print('sglang', sglang.__version__)"
EOF

Install uv and Rust, clone sgl-project/SpecForge, then install it in editable mode. To work on your own fork over SSH, add the SSH key example and clone git@github.com:<you>/SpecForge.git instead.

set -euo pipefail
source "$RADIX_UP_LIB"

push files

remote <<'EOF'
set -euo pipefail

# Toolchain (rootless)
command -v uv >/dev/null || curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
command -v cargo >/dev/null || curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"

# SpecForge from source
cd ~
[[ -d SpecForge ]] || git clone https://github.com/sgl-project/SpecForge.git
cd SpecForge

# Virtual env + editable install
[[ -d .venv ]] || uv venv -p 3.11 --seed
source .venv/bin/activate
uv pip install -v -e . --prerelease=allow
EOF

Install the Codex CLI and reuse your ChatGPT login. Avoid using the same login on several machines at once: token refreshes can sign the others out.

set -euo pipefail
source "$RADIX_UP_LIB"

# Your ChatGPT login from `codex login` on this machine
push ~/.codex/auth.json .codex

remote <<'EOF'
set -euo pipefail
chmod 700 ~/.codex && chmod 600 ~/.codex/auth.json
grep -q '^cli_auth_credentials_store' ~/.codex/config.toml 2>/dev/null \
  || echo 'cli_auth_credentials_store = "file"' >> ~/.codex/config.toml

[[ -x ~/.local/bin/codex ]] || curl -fsSL https://chatgpt.com/codex/install.sh | sh
grep -q 'HOME/.local/bin' ~/.bashrc || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc

~/.local/bin/codex --version
~/.local/bin/codex login status
EOF

Install Claude Code and authenticate with a long-lived token from claude setup-token stored in files/.radix_env. Or run claude on the node and log in with the URL + code flow.

set -euo pipefail
source "$RADIX_UP_LIB"

# files/.radix_env contains: CLAUDE_CODE_OAUTH_TOKEN=...  (from `claude setup-token`)
push files

remote <<'EOF'
set -euo pipefail
grep -q radix_env ~/.bashrc 2>/dev/null \
  || echo '[ -f ~/.radix_env ] && set -a && . ~/.radix_env && set +a' >> ~/.bashrc
# `radix shell` is a login shell: make ~/.profile load ~/.bashrc
grep -q bashrc ~/.profile 2>/dev/null \
  || echo '[ -n "$BASH_VERSION" ] && [ -f ~/.bashrc ] && . ~/.bashrc' >> ~/.profile

[[ -x ~/.local/bin/claude ]] || curl -fsSL https://claude.ai/install.sh | bash
grep -q 'HOME/.local/bin' ~/.bashrc || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
grep -q DISABLE_AUTOUPDATER ~/.radix_env || echo 'DISABLE_AUTOUPDATER=1' >> ~/.radix_env

~/.local/bin/claude --version
EOF
